# Contributing and security

Contributions must preserve RevokeTrace's bounded, read-only and fail-closed behavior. Use the pinned Rust toolchain, locked builds, tests, formatting and strict Clippy checks.

See [CONTRIBUTING.md](https://github.com/RevokeTrace/revoketrace/blob/main/CONTRIBUTING.md) for setup, fixture provenance, source verification, commit practices and pull-request expectations.

For vulnerabilities, follow [SECURITY.md](https://github.com/RevokeTrace/revoketrace/blob/main/SECURITY.md). Do not disclose exploit details in public issues. The security policy describes the repository's private reporting availability and safe alternatives.
